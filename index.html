How to Use

PC/Laptop Controls

Mouse Left-Click drag: Move the map

Mouse Right-Click drag: Zoom in / out

Mouse Wheel-Click drag: Tilt and rotate

Ctrl + Left-Click drag: Tilt and rotate

Mouse Wheel Turn: Zoom in / out

Mobile Touch Controls

One finger drag: Move the map

Pinch: Zoom in / out

Two finger drag: Tilt and rotate

Features

Search: Find buildings by number or name

Directions: Click a building, then tap "Directions" to route from GPS, map pick, or another building

Set My Location: Manually set your position on the map

Start Trip: Begin turn-by-turn walking navigation (GPS mode only)

Reset Camera: Return to the full campus view
